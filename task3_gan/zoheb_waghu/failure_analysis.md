## Visual quality

Evidence: [outputs/plots/translation_examples.jpg](outputs/plots/translation_examples.jpg) - 6 fixed
random triplets per direction (input | translation | cycle reconstruction).

| Measure | Monet → photo (A2B) | Photo → Monet (B2A) |
|---|---|---|
| FID / KID | 103.197 / 0.0182 | 98.855 / 0.0076 |
| Precision (realism) / recall (diversity) | 0.703 / 0.480 | 0.507 / 0.680 |
| LPIPS input vs translation (how much changed) | 0.354 | 0.378 |
| Content cosine input vs translation | 0.797 | 0.772 |

A successful translation keeps the horizon, silhouettes and object positions while changing the
rendering style. In the examples, A2B usually reduces brush texture, sharpens edges and increases
photographic contrast. B2A adds broken colour and softer boundaries while leaving the main
objects in place. The round trips generally restore the source layout.

The failures differ by direction. Some A2B outputs remain painterly, while others become much
darker. B2A can cover a sparse sky or dark silhouette with broad paint texture. In several of
the strongest examples, however, the reconstruction restores details that are barely visible in
the translation. The translation suppresses those details visually, but they remain recoverable.
CycleGANs can satisfy cycle loss by carrying source information in subtle high-frequency signals, as
described by [Chu, Zhmoginov and Sandler (2017)](https://arxiv.org/abs/1712.02950). The low cycle
errors here are consistent with that mechanism, though they do not prove that this model uses it.

## Cycle-consistency verification

Every evaluated image was translated and translated back, then the reconstruction was compared
with the original (`outputs/cycle_A/`, `outputs/cycle_B/`, regenerated by `src/infer.py`).

| Measure | A → B → A | B → A → B |
|---|---|---|
| Mean absolute pixel error, [0, 1] scale | 0.0332 (≈ 8.5 / 255) | 0.0398 (≈ 10.2 / 255) |
| Worst single image in the evaluated 300 | 0.0650 (`4f7e01f097.jpg`) | 0.1378 (`0845e8dc24.jpg`) |
| Training cycle L1 (unweighted, both directions) | first 50 logged steps 0.497 → final 10% 0.132 | |

The round trip is asymmetric. A → B → A averages 0.0332, while B → A → B is about 20% higher at
0.0398. In the worst B2A case, `0845e8dc24.jpg`, tightly repeated orange-red clouds become
blue/cyan. The reconstruction keeps much of that blue cast and does not restore the original
spacing or local contrast. Its 0.1378 pixel error is more than twice the worst A2B error, so the
difference is larger than ordinary JPEG variation.

The worst A2B example, `4f7e01f097.jpg`, retains the river and foliage layout but softens leaves,
flattens reflections and shifts the greens. Cycle loss preserves coarse structure well on
average, yet it permits an approximately invertible colour and texture mapping that need not
look faithful at each intermediate step. The residual stack operates on 64×64×256 activations,
or 1,048,576 values, compared with 196,608 values in the input. Activation count therefore
cannot explain the missing detail by itself. Learned strided operations, normalisation and the
loss trade-off are more plausible places to investigate.

## Training stability

Curves: [outputs/plots/training_curves_t3_baseline_20260929-235720.png](outputs/plots/training_curves_t3_baseline_20260929-235720.png)

| Signal | Value |
|---|---|
| NaN / non-finite steps | 0 of 281,520 |
| Generator gradient norm, mean over run | 23.36 |
| Largest gradient spikes | 527.3 (step 142,550, epoch 21), 165.3 (step 218,050), 131.8 (step 36,800), 130.5 (step 148,000) |
| Discriminator loss, first 50 steps → final 10% | 0.483 → 0.251 |
| Generator loss, first 50 steps → final 10% | 8.151 → 2.970 |
| LR | 2e-4 constant for 20 epochs, linear decay to 0 over 20 |

Training remained finite for all 281,520 steps. The training losses fall fastest during the first
ten epochs, but checkpoint quality improves more from epoch 10 to 20: the proxy drops by 3.58
points, compared with 1.39 from epoch 5 to 10. During epochs 11–40, the per-epoch discriminator
mean ranges from 0.245 to 0.310. In this implementation, a discriminator that predicts 0.5 for
every real and fake patch gives a combined loss of 0.5, while perfect separation gives 0. A loss
near 0.25 therefore still represents useful separation; it does not establish that generator
and discriminator were evenly matched.

The score changes little after epoch 20, during the same interval in which the learning rate
decays to zero. Without a run that holds the rate constant beyond epoch 20, the effect of decay
cannot be separated from the effect of additional epochs.

The 527.3 gradient norm at step 142,550 is isolated at the logging resolution. Records are 50
steps apart, so the unseen batches prevent a single-batch diagnosis. Step 142,450 had a raised
generator loss of 6.56 and cycle loss of 0.338; at the spike they were 4.07 and 0.19. The next
logged norm was 20.1, and the run showed no later non-finite value or sustained loss increase.
The code records the norm without clipping it, so the log shows recovery by the next recorded
point but does not identify which loss term caused the event.

## Human audit (30 fixed samples, 2 raters)

Blinded: 15 samples per direction, drawn with seed 42 from the first 300 sorted predictions (the
set the instructor's evaluator scores), shuffled, file names stripped. Each sheet shows
**source | translation** side by side so content preservation can be judged. Raters scored style,
content and artifacts 1-5 with **5 best on every axis**, independently, against
[outputs/RATING_GUIDE.md](outputs/RATING_GUIDE.md).

| Metric | Rater 1 | Rater 2 | κ | exact | within 1 |
| --- | --- | --- | --- | --- | --- |
| Style | 3.23 | 3.30 | 0.153 | 66.7% | **100%** |
| Content | 4.57 | 4.47 | 0.141 | 56.7% | **100%** |
| Artifacts | 4.77 | 4.70 | 0.153 | 66.7% | **100%** |

Per direction: A2B (Monet → photo) style 3.17 / content 4.57 / artifacts 4.63; B2A (photo →
Monet) style 3.37 / content 4.47 / artifacts 4.83.

**Inter-rater agreement: Cohen's κ = 0.1487, exact agreement 63.3%, 100% of ratings within one
point.**

### Two rounds, and why κ is low

A first round was rated before the guide existed and produced **κ = −0.05** — agreement worse than
chance. Per-axis diagnosis showed the cause was definitional, not perceptual: `artifacts` was
negative on every measure, the signature of the two raters scoring the axis in opposite directions
(disagreeing over whether 5 meant "clean" or "many artifacts"), while `content` already agreed
(quadratic κ 0.41). The guide was written with explicit 1-5 anchors and the **same 30 sheets** were
re-rated. Round 1 is retained at
[outputs/human_audit_ratings_round1.csv](outputs/human_audit_ratings_round1.csv).

κ = 0.1487 still reads as "slight" on the Landis-Koch scale, which understates the result. Both
raters used only **two of the five categories** on each axis, so chance agreement is already
50-61% and κ gives little credit for beating it:

| Axis | categories used | chance agreement | observed | κ |
| --- | --- | --- | --- | --- |
| Style | {3, 4} | 60.7% | 66.7% | 0.153 |
| Content | {4, 5} | 49.6% | 56.7% | 0.141 |
| Artifacts | {4, 5} | 60.7% | 66.7% | 0.153 |

This is the kappa paradox: high observed agreement with skewed marginals yields a low κ. It is
also why unweighted and quadratic-weighted κ are identical here — weighting only differs when some
disagreements span more than one category, and **none in this audit do**. The honest summary is
that the raters never differed by more than one point, and κ is deflated by low category variance
rather than by real disagreement.

### What the audit says about the model

Content (4.47-4.57) and artifacts (4.63-4.83) are strong: the model keeps the scene and produces
clean images. **Style (3.17-3.37) is the weak axis in both directions**, and the human verdict
agrees with the computed metrics — FID 103.2 / 98.9 and a comparatively small LPIPS change from
the input. This model is conservative: it protects content and avoids artifacts at the cost of
committing to the target style, which is the same trade-off the cycle-consistency and
content-cosine numbers show above.

## Shortcomings

This run has four measured constraints:

- Epoch budget 20 + 20, not the paper's 100 + 100.
- Single run, single seed - no run-to-run variance estimate.
- FID / MiFID on 300 images per set (the instructor's protocol); FID is biased upward at this
  sample size.
- Monet domain has 300 images against 7,038 photos; each Monet image is seen ~23× per epoch.

The 300-to-7,038 domain imbalance is the first limitation I would investigate. Each Monet image
is sampled about 23 times per epoch, and B2A precision is low relative to its recall. This makes
limited target variation a plausible cause, though this run does not isolate it. The epoch budget
remains another possibility because the apparent plateau overlaps exactly with learning-rate
decay. There is no constant-rate run beyond epoch 20, so the evidence cannot rank those two
causes confidently.

I would run two controlled tests. The first would compare the current decay with a constant
learning rate beyond epoch 20 while keeping architecture, data and updates fixed. The second
would strengthen crop and colour augmentation on the official Monet set, again with matched
updates. External images would only be considered if the assignment rules explicitly permit
them. B2A precision and KID would be the primary outcomes, with recall checked for mode collapse.
Each condition needs three seeds because this run has no variance estimate. The required 300-image
FID protocol should stay unchanged for comparison, while bootstrap intervals could show how
much of a small score difference is sampling noise. The two-rater audit also needs to be finished
before drawing conclusions about perceived style or artifacts.
